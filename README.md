# sudoku-rs
### A sudoku solver and game player, built in Rust

## Supported Features

### Solver
* Solve any sudoku puzzle.
* Puzzles can be loaded from file
* See `examples` folder for examples of how to format game files.

### Player
* (Not yet implemented)

## Usage

```
Usage: sudoku <COMMAND>

Commands:
  play   Play a game
  solve  Solve an existing puzzle from file
  help   Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
```

#### solve

```
Solve an existing puzzle from file

Usage: sudoku solve <FILENAME>

Arguments:
  <FILENAME>

Options:
  -h, --help  Print help
```
